Guía de Diseño Institucional

Un solo diseño para todos los módulos. Si cada participante sigue esta guía, el sistema completo se verá como si lo hubiera hecho una sola persona.

1

Copia design-system.css junto a tus archivos. No lo edites.

2

Duplica plantilla-modulo.html y renómbrala con el nombre de tu módulo.

3

Construye tu contenido dentro de <main> copiando los componentes de esta guía.

Reglas obligatorias

✔ Sí

  • Usar solo clases .ds-* para la interfaz.
  • Usar variables: color: var(--azul-800), padding: var(--esp-4).
  • Un solo botón primario por pantalla o formulario (la acción principal).
  • Títulos: un <h1> por página, luego <h2>, <h3> en orden.
  • Textos de botones con verbo: “Guardar”, “Buscar”, “Exportar”.
  • Todo campo con <label>; obligatorios marcados con *.
  • Mensajes al usuario con .ds-alerta.
  • Si falta un componente, pedirlo al responsable del diseño.

✘ No

  • Editar design-system.css por tu cuenta.
  • Escribir colores a mano (#3366ff, red, blue…).
  • Cambiar la fuente, el encabezado, el menú lateral o el pie.
  • Usar Bootstrap, Tailwind u otro framework de estilos.
  • Usar verde/rojo/amarillo como decoración: solo para estados.
  • Tamaños de texto fuera de la escala (nada de font-size: 19px).
  • Estilos en línea (style="...") salvo casos mínimos.
  • Textos en MAYÚSCULAS completas o con varios signos (!!!).

Tipografía

Fuente única: Source Sans 3 (se carga sola desde el CSS). Solo pesos 400, 600 y 700.

Título de página · 32px / 700

Título de sección · 24px / 700

Subtítulo · 20px / 600

Texto normal · 16px / 400. Es el tamaño de todo el contenido general del sistema.

Texto secundario · clase .ds-texto-sec

Texto de ayuda · 14px · clase .ds-texto-ayuda

Estructura de página

Todas las pantallas comparten encabezado azul, menú lateral, contenido y pie. Ya viene armado en plantilla-modulo.html; en celular el menú se oculta tras el botón ☰.

.ds-header
.ds-sidebar
.ds-main — tu módulo aquí
.ds-footer
<!-- Encabezado de cada pantalla dentro de <main class="ds-main"> -->
<ol class="ds-breadcrumb">
  <li><a href="#">Inicio</a></li>
  <li>Nombre del módulo</li>
</ol>
<div class="ds-page-header">
  <h1>Nombre del módulo</h1>
  <button class="ds-btn ds-btn--primario">+ Nuevo registro</button>
</div>

<!-- Rejillas: ds-grid + ds-grid-2 / ds-grid-3 / ds-grid-4 -->
<div class="ds-grid ds-grid-3"> ... </div>

Botones

<button class="ds-btn ds-btn--primario">Guardar</button>      <!-- acción principal, 1 por pantalla -->
<button class="ds-btn ds-btn--secundario">Cancelar</button>   <!-- acción alternativa -->
<button class="ds-btn ds-btn--texto">Ver detalle</button>     <!-- acción menor -->
<button class="ds-btn ds-btn--peligro">Eliminar</button>     <!-- solo acciones destructivas -->
<button class="ds-btn ds-btn--primario ds-btn--sm">Pequeño</button>  <!-- dentro de tablas -->

Formularios

Ingresa un correo válido.
Formato día/mes/año. 
<div class="ds-campo">
  <label class="ds-label" for="nombre">Nombre<span class="req">*</span></label>
  <input class="ds-input" id="nombre">
  <span class="ds-texto-ayuda">Texto de ayuda opcional</span>
</div>

<!-- Con error: agrega ds-campo--error y el mensaje -->
<div class="ds-campo ds-campo--error">
  <label class="ds-label" for="correo">Correo</label>
  <input class="ds-input" id="correo">
  <span class="ds-campo__error">Ingresa un correo válido.</span>
</div>

<select class="ds-select">...</select>
<textarea class="ds-textarea"></textarea>
<label class="ds-check"><input type="checkbox"> Opción</label>

<!-- Botones al final: Cancelar a la izquierda, Guardar a la derecha -->
<div class="ds-form-acciones">
  <button class="ds-btn ds-btn--secundario">Cancelar</button>
  <button class="ds-btn ds-btn--primario">Guardar</button>
</div>
